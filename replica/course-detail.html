Ascend C异构并行程序设计 V2.0

Ascend C异构并行程序设计 V2.0

在学216人 课时32h 课程等级高级 语言中文 学习类型由教师指导,在线自学

课程介绍

本课程系统讲解从异构计算、昇腾 AI 处理器与 CANN 软件栈，到 Ascend C 的 SIMD / SIMT 编程、编译运行、功能调试、性能优化和工程集成。课程以算子开发全生命周期为主线，规划通过典型案例串联 计算特征解析 → 基础版本实现 → 性能剖析 → 瓶颈定位 → 优化方案设计 → 效果验证，并进一步延伸至混合编程、AI 框架集成、通信编程、大模型辅助开发、扩展库与 Python 生态。

课程目录

课程导学
第一部分：算子编程原理
第二部分: 算子编程基础
第三部分: 算子编程案例
第四部分: 算子编程进阶

课程团队

苏统华
哈工大软件学院副院长，教授，博士生导师

你将掌握以下核心能力

掌握昇腾Ascend C算子编程原理，精通SIMD与SIMT模型及调试优化。具备Softmax、FlashAttention等主流算子开发实战能力，掌握混合编程、框架集成、通信及大模型辅助开发等进阶技能。
