课程介绍

本课程系统讲解从异构计算、昇腾 AI 处理器与 CANN 软件栈，到 Ascend C 的 SIMD / SIMT 编程、编译运行、功能调试、性能优化和工程集成。课程以算子开发全生命周期为主线，规划通过典型案例串联 计算特征解析 → 基础版本实现 → 性能剖析 → 瓶颈定位 → 优化方案设计 → 效果验证，并进一步延伸至混合编程、AI 框架集成、通信编程、大模型辅助开发、扩展库与 Python 生态。
