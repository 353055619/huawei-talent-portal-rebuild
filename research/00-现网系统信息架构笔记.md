# 华为人才在线（e.huawei.com/cn/talent/portal）现网信息架构笔记

> 调研日期：2026-11-15。以下为未登录状态下逐页浏览的一手记录。

## 站点结构：门户是"壳"，多个子应用拼装

| 频道 | 实际 URL | 说明 |
|---|---|---|
| 首页 | `e.huawei.com/cn/talent/portal/#/` | 华为人才在线主页：热门课程轮播 |
| 学习 | `e.huawei.com/cn/talent/learning/#/ict-academy` | 课程目录/全部课程/我的学习 |
| 认证 | `e.huawei.com/cn/talent/cert/#/careerCert` | 职业认证全景图 |
| 华为ICT学院 | `e.huawei.com/cn/talent/ict-academy/#/home` | 校企合作项目主站 |
| 华为ICT大赛 | `e.huawei.com/cn/talent/ict-academy/#/ict-contest?compId=...` | 大赛报名/资讯/往届 |
| 培训伙伴(HALP) | `e.huawei.com/cn/talent/halp/#/home?navType=halp` | 授权培训伙伴 |
| 企业培训 | 点击后新标签打开 `e.huawei.com/cn/solutions/services/learning-and-certification` 及 `elearning.huawei.com/cn/homepage` | 与 HALP 同 URL 或外链，体验割裂 |
| 成功案例 | `e.huawei.com/cn/talent/success-stories/#/home` | ICT大赛获奖故事为主 |
| 商城 | 新标签打开 `elearning.huawei.com/cn/homepage`（华为认证官网/elearning，另一套系统） | 外链跳转，非本门户 |

**关键架构事实**：顶部导航 8 个频道中，至少 3 个（企业培训/商城/部分资源）跳出到独立系统（elearning.huawei.com 等）；"企业培训"与"培训伙伴"落地页相同。整个"人才在线"由 ≥5 个独立 SPA 子站拼成，账号走 uniportal.huawei.com 华为账号。

## 登录
- 华为统一账号（uniportal.huawei.com）：手机号/邮箱/账号名+密码、短信验证码登录、注册、忘记密码。

## 各频道要点

### 学习（learning）
- 课程目录三种视图：专业课程目录 / 岗位课程目录 / 全部课程
- 专业维度：计算机科学与技术、人工智能、软件工程、物联网工程
- 课程分层：实践课（专业综合实训）、核心课（算子开发、并行计算、编译原理、计组、数据结构等）、通识课（AI通识、智能体与AI编程、计算机系统通识等）
- 筛选器：专业 / 岗位 / 技术方向 / 课程类型 / 难度级别；排序：学习量 / 发布时间
- 课程卡片：类型标签（院校课程）、学习人数、时长（h）、难度、报名按钮、分享
- 总量 133 条（12页）；首页另有"慕课"卡片（免费+人数）
- 大量课程绑定昇腾/CANN/鲲鹏/仓颉等华为技术栈（教材国产化的载体）
- "我的学习"入口存在（需登录）

### 认证（cert）
- 职业认证全景图：HCIA（工程师）/HCIP（高级工程师）/HCIE（专家）三级
- 方向分类：ICT基础设施（Datacom/WLAN/Security/Transmission/Access/5G/LTE/MDC）、基础软硬件（Computing/Storage）、云平台及云服务、项目管理
- 参加考试：笔试由 Pearson VUE 代理（外链）；电子证书考后1个工作日可下载；HCIE 例外
- 重认证规则、授权培训机构查询、《华为ICT认证系列丛书》
- 认证资讯公告列表

### 华为ICT学院（ict-academy）
- 三类角色入口：成为华为ICT学院（注册/认证/续认证）、成为ICT学院教师（注册关联/开班开课/资料下载）、成为ICT学院学生（注册关联/学习/资料下载）
- 数据：110+国家、3500+学院、11000+教师、年培养500,000+学生
- IASC（ICT Academy Support Center）支持：教师赋能/拓展支持/运营管理/活动支持
- 产学合作：协同育人/案例展示
- 就业：全球每年数十场人才双选会、1000+合作招聘企业、近千岗位（"优先就业"卖点）
- 首页模块：课程目录、资源中心（课程/资料/工具）、ICT大赛、产学合作、资讯中心

### 华为ICT大赛（ict-contest）
- 本届报名 187,560 人；累计 1,180,000+；2000+院校；100+国家
- 7 条赛道：实践赛（网络/云/基础软件）、创新赛、教学赛（教师·产教融合）、挑战赛（昇腾+鲲鹏调优）、编程赛（仓颉）、算子赛（昇腾C算子开发）、精英赛（商业/toB销售）

- 大赛手册/路演胶片为 PDF 附件（filepreview 链接）
- 往届回顾：第1~10届 tab；榜首SHOW；中国区纳入全国普通高校大学生竞赛榜单，海外纳入UNESCO全球技能学院旗舰项目

### 培训伙伴 HALP（halp）

## 补充发现（公开页面深挖，2026-11-15 二次遍历）

### 入驻旅程：注册按钮跳出门户
- ICT学院首页三个"立即注册"按钮：
  - **成为华为ICT学院（学校）** → 新标签打开 `uniportal.huawei.com` 登录后跳 `partner.huawei.com/eplusweb/#/cn/web/become-an-ict-academy`——学校注册在**华为伙伴系统（partner.huawei.com）**，不在人才在线门户内
  - 成为ICT学院教师/学生的注册也走 uniportal（待登录后验证落点）
- 即：**学校入驻（partner.huawei.com）与学生学习（e.huawei.com/cn/talent/*）是两套系统**，院校老师日常要在两个系统间切换

### 标签页行为
- 门户内大量操作（查找ICT学院、注册、商城等）都是 **新开标签页**，未做站内路由；一次会话轻松累积 7+ 个标签页，多标签间无面包屑/返回路径设计

### 查找ICT学院（talent/#/organization/search?type=Academy）
- 筛选：伙伴类型（默认ICT学院）/伙伴层级/伙伴名称
- **点"查询"若只保留默认类型会弹窗"请至少输入一个查询条件"**——不能浏览全量目录，无地图视图、无地区筛选（对比思科 NetAcad 有全球 Academy Locator 地图检索）
- 名称模糊搜"大学"返回 258 条：学院名/地址/网址/国家/层级（认证级、领先级·双一流）/授权产品（12 个技术方向）
- 数据本身不错，但检索维度太弱（无省市、无高校类型、无合作起始年份等）

### HALP 资讯公告
- 最新公告 2023 年（更新停滞），侧面反映运营带宽不足

### 用户中心（usercenter/#/home）
- 首页主区域**空白**：无概览、无待办聚合、无快捷入口，只有左侧菜单（我的课程/班级/大赛/个人信息/券包/证书/考试/消息）
- **左侧菜单只在 `#/home` 渲染**；进入任何子页面（mycourse/myclass-list/myComp/my-coupons/my-news/myinfo）后菜单消失，模块间无法切换，只能浏览器后退——硬伤
- 账号下拉菜单仅 4 项：用户中心/我的课程/个人信息/实名认证/退出
- "我的证书""我的考试"实际跳到**另一个子应用** `talent/#/personal/mycert`、`talent/#/personal/myappointments/list`（布局都变了），证书页的"企业关联"又跳 `e.huawei.com/cn/myspace/...` 第三套系统

### 各模块
- **我的课程**：全部/在线课程/实验案例/学习中/已结束；公告①班级课程不在此显示要去我的班级 ②"由于平台升级，建议前往【学习】页面重新学习"——学习记录迁移断档
- **我的班级**：组织方/班级状态/名称筛选 + **邀请码加入**——学生进班唯一方式是邀请码，无"本校班级"浏览
- **我的大赛**：空页面，空态无任何引导 CTA
- **我的券包**：暗码考券/数字考券、考券记录；规则文本暴露复杂状态机（占用后 24h 自动取消、HCIE 需提前 7 天约考）；`#/voucher/application` 考券申请路由**空白页**
- **我的证书**：认证证书/结课证书；关联其他账号证书、关联Upgrade成绩；电子证书 1-3 工作日生成；HCIE 纸质套件 15/30 工作日；企业关联变更需间隔 12 个月
- **我的考试**：职业&专业认证考试/其他考试；VUE考试记录/收据按钮；是否在线预约筛选
- **我的消息**：待办事项(0)/消息提醒(0)/平台公告(0) 三 tab
- **个人信息**：姓字段被填成账号 ID（数据质量）；实名认证按钮点击后只改 URL（`#/realinfosystem`）内容不变（疑似弹层渲染问题）；**角色关联**：关联-讲师/关联-学生按钮 → 向导（国家/我的学院选择器/专业/学历/班级/学号/入学毕业年月/备注+隐私声明），姓名"确定后将无法修改"；无学校 SSO/学信网式可信认证，靠自填+审批

## 初步观察（待登录后验证）
1. 门户=营销+目录，核心交易（报名/开班/考试预约/双选会）分散在不同子站/外部系统
2. 同一账号体系（华为账号）但多子系统跳转，上下文丢失；学校入驻甚至在另一套伙伴系统
3. 公开页面未见：就业/双选会专区入口（只在ICT学院页有一句文案）、企业招聘端、院校管理端入口（需登录后确认）
4. "企业培训"与"培训伙伴"导航重复；"商城"外链 elearning
5. 学院目录检索弱：无地图/地区浏览，强制输入条件
6. 大赛资料以 PDF 附件交付（手册/胶片），无结构化内容运营
